# 提炼规范（可执行版）

定稿：2026-11-12（v1.2）。**本文件是提炼环节的唯一口径**：口头偏好、历史笔记、记忆里的做法与它冲突时，一律以本文件为准，因为本文件跟着技能一起走、可被核对。

## 一、十九条硬规则

| # | 规则 | 执行含义 |
|---|---|---|
| 1 | 五块硬编码，顺序不变 | 报告名 → 信源（含元数据）→ 信源简介 → 核心观点 → 推导过程 |
| 2 | 观点条数跟报告条目走 | 有编号要点按条数抽；无则走第 3 条 |
| 3 | 无编号要点的兜底 | 定位 conclusion / key findings / 摘要末段，逐句抽成判断，合并同义项；可再从各章末段补抽并注明来源章节；总数≤7 |
| 4 | 推导用逻辑重排 | 四段：前提→机制→证据→结论；每步标页码 |
| 5 | 证据精度 | 每条观点挂 `p.X` + 原文摘句，摘句不得改词 |
| 6 | 类型约束写法 | 概念框架不得写因果断言；实证研究必须带样本与时期；建模预测须标「测算/情景」 |
| 7 | 类型四步判定 | ①原创数据或一手调查→实证研究 ②公开数据算指数或情景推演→建模预测 ③只给框架无数据→概念框架 ④问卷问高管→企业调查 |
| 8 | 数字原地注释 | 例：29%（任务暴露率，非失业率；84 国样本，2026） |
| 9 | 局限强制单列 | 作者未写则写「原文未提供局限性说明」 |
| 10 | 禁止无标补写 | 报告外内容另起一行标「整理者补充」 |
| 11 | 推导区允许四段小标题 | 只用「前提／机制／证据／结论」四个；下方每句仍须自足 |
| 12 | 空话拦截用三测试 | 见第五节 |
| 13 | 三种声音分开 | 报告事实直陈；作者主张标「作者认为」；整理者推断标「整理者判断」 |
| 14 | 名称首现双语 | 生成式人工智能（Generative AI） |
| 15 | 8 条自检 | 见第五节 |
| 16 | 失败样本存档 | 被退回的输出连原因记入 `references/failures.md` |
| 17 | 元数据五项必填 | 作者、机构、发布日期、页数、原文链接；缺项明写「报告未提供」，不许留空 |
| 18 | 句子自足 | 每句脱离上下文可读；禁止「标题+副标题」「上半句+补注」两截拼；主语不得省 |
| 19 | 机构与类型以正文为准 | 文件名与正文冲突时以版权页为准，并在「整理者补充」注明差异 |

## 二、语言规则

1. 一句一判断。抽任意一句单独看，读者不知道上下文也要能懂。
2. 主语不得省。「技术」写清是哪类技术，「市场」写清是买方还是卖方。
3. 不用编号或小标题承重：删掉标签，句意仍完整。
4. 引号用直角引号「」，嵌套用『』。
5. 不写「赋能、重塑、深刻影响、双刃剑」。判定不靠词表，靠第 12 条三测试。

## 四、页码约定

一律用 **PDF 文件页序**，不是印刷页码。两者不同时在 `page_note` 里写「PDF 文件页序；印刷页码 p.X」。

## 五、八条自检

| # | 检查项 | 判定 |
|---|---|---|
| 1 | 每句脱离上下文可读 | 抽任意一句单看 |
| 2 | 每条观点有页码 + 摘句 | 逐条核 |
| 3 | 每个数字带口径 | 搜索全部阿拉伯数字逐个核 |
| 4 | 类型与写法一致 | 概念框架有无因果断言；实证有无样本与时期 |
| 5 | 局限已单列 | 非空；无则写明未提供 |
| 6 | 三种声音已区分 | 有无把整理者判断写成作者结论 |
| 7 | 无未标注补写 | 报告外内容是否都挂了「整理者补充」 |
| 8 | 空话三测试 | ①删掉专名与数字，骨架仍能套别的话题 ②反面同样成立 ③无数字无可核对对象。命中即入 `suspicious` |

## 六、常见坑

- **把暴露率写成失业率**。暴露是「任务可能被碰到」，失业是「人已经失去岗位」，两者不可互换。
- **把工时占比写成岗位占比**。McKinsey 的 57% 是工时，不是岗位。
- **修订版当原版引**。Stanford 那份 2026-08 修订版正文是 19%，旧版回归估计是 13%/16%，引用前先看版权页日期。
- **年化与累计混用**。NBER w34836 的 0.2% 是年化，0.5% 是三年累计，同一结果两套单位。
- **把机构名与作者单位混为一谈**。Hamilton Project 是布鲁金斯旗下，作者才是 MIT 教授。
